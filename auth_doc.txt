	<h3>Authentication Endpoint - <small><code>Post Request</code></small></h3>
<p>Pesapal's API Authentication requests are done via a POST request.</p>
<p>Your Pesapal merchant <strong>consumer_key</strong> and <strong>consumer_secret</strong> will be used to generate an access token.</p>
<p>This access token is valid for a maximum period of <strong>5 minutes.</strong> Use this token (sent as a Bearer Token) to access all other Pesapal API 3.0 endpoints.</p>
<p>The URL to our token generation API is either:</p>
<ul>
<li><strong>Sandbox/Demo URL: </strong><a href="https://cybqa.pesapal.com/pesapalv3/api/Auth/RequestToken" target="_blank">https://cybqa.pesapal.com/pesapalv3/api/Auth/RequestToken</a></li>
<li><strong>Production/Live URL: </strong><a href="https://pay.pesapal.com/v3/api/Auth/RequestToken" target="_blank">https://pay.pesapal.com/v3/api/Auth/RequestToken</a></li>
</ul>
<h4><span style="text-decoration: underline;">HTTP request headers</span></h4>
<p><strong>Accept: </strong>The response format, which is required for operations with a response body.<br /> <strong>Content-Type: </strong>The request format, which is required for operations with a request body.</p>
<table>
<thead>
<tr><th><span>Parameter </span></th><th><span>Required</span></th><th><span>Description</span></th></tr>
</thead>
<tbody>
<tr>
<td><span>Accept</span></td>
<td><code><span>Required</span></code></td>
<td><span> Should be set to </span><code><span>application/json</span></code></td>
</tr>
<tr>
<td><span>Content-Type</span></td>
<td><code><span>Required</span></code></td>
<td><span> Should be set to </span><code><span>application/json</span></code></td>
</tr>
</tbody>
</table>
<p> </p>
<h4><span style="text-decoration: underline;">Request Parameters</span></h4>
<p>Your live/production <strong>consumer_key</strong> and <strong>consumer_secret</strong> will be sent to your merchant email on opening a business/merchant account.</p>
<p>Please click <a href="https://www.pesapal.com/dashboard/account/register" target="_blank">here</a> to open a live/production business account.</p>




<div class="callout warning">
Click <a href="/api3-demo-keys.txt" target="_blank">here</a> to download test credentials to use while connecting to our <strong>demo/sandbox</strong> API.
</div>




<table>
<thead>
<tr><th>Parameter</th><th>Type</th><th>Required</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td>consumer_key</td>
<td>String</td>
<td><code>Required</code></td>
<td>The consumer_key parameter must be set to <code>merchant consumer_key</code></td>
</tr>
<tr>
<td>consumer_secret</td>
<td>String</td>
<td><code>Required</code></td>
<td>The consumer_secret parameter must be set to <code>merchant consumer_secret.</code></td>
</tr>
</tbody>
</table>
<p> </p>
<h6>Sample Request</h6>
<pre class="brush: xml">    {
        "consumer_key": "xxxxx",
        "consumer_secret": "xxxxxx"
    }
</pre>
<p> </p>
<h4><span style="text-decoration: underline;">Response Parameters</span></h4>
<p> </p>
<table>
<thead>
<tr><th><span>Name</span></th><th><span>Type</span></th><th><span>Description</span></th></tr>
</thead>
<tbody>
<tr>
<td><span>token</span></td>
<td><span>String</span></td>
<td><span>The access token string as issued by the server. The access token issued will have permission to invoke all Pesapa API operations.</span></td>
</tr>
<tr>
<td><span>expiryDate</span></td>
<td><span>String</span></td>
<td><span>Date and time the token will expire. The access token usually expires after 5mins - </span><code><span>UTC</span></code></td>
</tr>
<tr>
<td><span>error</span></td>
<td><span>Object</span></td>
<td><span>Error object</span></td>
</tr>
<tr>
<td><span>status</span></td>
<td><span>String</span></td>
<td><span>Response code</span></td>
</tr>
<tr>
<td><span>message</span></td>
<td><span>String</span></td>
<td><span>A brief description about the response received.</span></td>
</tr>
</tbody>
</table>
